# 0006. `cite-source` is model-invoked, with an enforcement gate

Status: accepted

Sources emerge during interviewing and implementation, not before. A mandatory up-front literature phase collects papers that never enter the model and recreates the rigid process that small, composable skills are meant to avoid.

So `cite-source` is reached for when a correlation or constant appears. The risk is that the agent forgets. G9 (citation integrity) is the safety net: it fails if a correlation tag in the code has no manifest key, no issue entry, or a validity range that does not contain the envelope.
