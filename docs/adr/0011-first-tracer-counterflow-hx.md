# 0011. First tracer slice: counterflow heat exchanger (ε-NTU)

Status: accepted

It has an exact solution (verification), a literature correlation for the film coefficient (citation and envelope), a simple balance to violate (fault injection), and a clear envelope. It exercises every gate and every skill.

The example is generic: constant specific heat, single phase, water-like properties.

Alternatives considered: pipe pressure drop (less to verify against), isentropic compressor (no clean analytical solution).
